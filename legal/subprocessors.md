# Orion Studio Preview Subprocessor Notice

## Not Applicable to the Preview

The macOS Apple Silicon Preview does not include an Orion-operated hosted
service, account, subscription, payment system, collaboration backend, AI
proxy, extension marketplace, or automatic update service. Accordingly, this
project does not publish a list of processors or subprocessors for an Orion
hosted service, and it does not invent an Orion legal entity or data-controller
relationship.

GitHub distribution, macOS platform services, and any agent, model provider,
source-control host, extension source, or other integration configured directly
by a user are governed by those providers' own terms and privacy practices.
They are not represented here as subprocessors engaged by an Orion entity.

## Upstream Zed Attribution

Orion Studio is derived from Zed and retains necessary attribution to Zed
Industries, Inc. The Zed subprocessor list previously reproduced in this file
describes vendors used for Zed's own hosted products and services. It is not an
Orion Studio subprocessor list and does not apply merely because Orion Studio
contains Zed-derived code.

Users who separately use a Zed hosted service should consult Zed's official
[Subprocessor List](https://zed.dev/subprocessors) and related Zed legal terms.

For Orion Studio Preview support and sensitive security reports, see
[SUPPORT.md](../SUPPORT.md) and [SECURITY.md](../SECURITY.md).
