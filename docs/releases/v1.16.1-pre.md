# Orion Studio v1.16.1-pre

This Orion Studio Preview is intended for external testing. It is pre-release
software, not a Stable release.

## Supported Download

- macOS 11.0 or later
- Apple Silicon (`arm64`) only
- `Orion-Studio-aarch64.dmg`
- `SHA256SUMS` for integrity verification

Download both assets from this GitHub Pre-release. Do not install the DMG if
its checksum differs, its Developer ID signature is invalid, notarization is
missing, or macOS Gatekeeper does not accept the installed application.

## Preview Highlights

- Orion Studio product, bundle, command-line, user-data, project-configuration,
  packaging, and support identities
- canonical `orion` CLI, `orion://` links, Orion IPC names, and `.orion` project
  configuration with explicit read-only compatibility for legacy inputs
- first-launch import before Orion Studio initializes persistence, with
  conflict detection, retryable failures, and no deletion of legacy data
- uninstall behavior that removes only verified Orion Studio content
- fail-closed release checks for brand identity, secrets, entitlements,
  immutable signed tags, Developer ID signing, notarization, and checksums
- local and independently configured AI/provider integrations inherited from
  the editor codebase

## Important Boundaries

This Preview does not include an Orion-operated account, subscription,
collaboration backend, AI proxy, extension marketplace, or automatic update
service. Third-party integrations have their own availability, terms, and data
practices. Preview updates are installed manually from GitHub Releases after
verifying the new checksum and Gatekeeper status.

Back up existing editor data before first launch. Read the complete
[installation and verification guide](https://github.com/orion-agents/orion-studio/blob/v1.16.1-pre/docs/installation.md)
and the
[Preview scope and known limitations](https://github.com/orion-agents/orion-studio/blob/v1.16.1-pre/docs/releases/preview-macos-arm64.md)
before installing.

Report non-sensitive defects through
[GitHub Issues](https://github.com/orion-agents/orion-studio/issues/new/choose).
Report vulnerabilities privately through a
[GitHub Security Advisory](https://github.com/orion-agents/orion-studio/security/advisories/new).
