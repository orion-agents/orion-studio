# Orion Studio v1.16.0-pre

This is the first Orion Studio Preview intended for external testing. It is
pre-release software, not a Stable release.

## Supported Download

- macOS 11.0 or later
- Apple Silicon (`arm64`) only
- `Orion-Studio-aarch64.dmg`
- `SHA256SUMS` for integrity verification

Download both assets from this GitHub Pre-release. Do not install the DMG if
its checksum differs, its code signature is invalid, or macOS Gatekeeper does
not accept the installed application.

## Preview Highlights

- Orion Studio product identity, bundle identity, command-line entry point,
  user-data paths, packaging, and support material
- background first-launch import that starts only after the first workspace
  frame is visible and does not overwrite existing Orion Studio files
- local and independently configured AI/provider integrations inherited from
  the editor codebase
- automatic updates and the inherited default HTML extension auto-install
  disabled while Orion-operated release services are unavailable

## Important Boundaries

This Preview does not include an Orion-operated account, subscription,
collaboration backend, AI proxy, extension marketplace, or automatic update
service. Third-party integrations have their own availability, terms, and data
practices.

Back up existing editor data before first launch. Read the complete
[installation and verification guide](https://github.com/orion-agents/orion-studio/blob/v1.16.0-pre/docs/installation.md)
and the
[Preview scope and known limitations](https://github.com/orion-agents/orion-studio/blob/v1.16.0-pre/docs/releases/preview-macos-arm64.md)
before installing.

Report non-sensitive defects through
[GitHub Issues](https://github.com/orion-agents/orion-studio/issues/new/choose).
Report vulnerabilities privately through a
[GitHub Security Advisory](https://github.com/orion-agents/orion-studio/security/advisories/new).
