# Racket

Racket support is available through the upstream-Zed [Racket extension](https://github.com/zed-extensions/racket), which Orion Studio consumes through extension compatibility.

- Tree-sitter: [upstream Zed fork `zed-industries/tree-sitter-racket`](https://github.com/zed-industries/tree-sitter-racket)

The [racket-language-server](https://docs.racket-lang.org/racket-language-server/index.html) is not yet supported in Orion Studio, please see [Issue #15789](https://github.com/orion-agents/orion-studio/issues/15789) for more information.
