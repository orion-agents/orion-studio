# Prisma

Prisma support is available through the upstream-Zed [Prisma extension](https://github.com/zed-extensions/prisma), which Orion Studio consumes through extension compatibility.

- Tree-sitter: [victorhqc/tree-sitter-prisma](https://github.com/victorhqc/tree-sitter-prisma)
- Language-Server: [prisma/language-tools](https://github.com/prisma/language-tools)
