# Zig

Zig support is available through the upstream-Zed [Zig extension](https://github.com/zed-extensions/zig), which Orion Studio consumes through extension compatibility.

- Tree-sitter: [tree-sitter-zig](https://github.com/tree-sitter-grammars/tree-sitter-zig)
- Language Server: [zls](https://github.com/zigtools/zls)
