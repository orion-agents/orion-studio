# Compliance Status

This repository does not claim that Orion Studio or any Orion-hosted service is
SOC 2 certified. The open-source desktop application and any separately
operated service have different compliance boundaries.

An operator must publish independently verifiable compliance reports and a
security contact before making certification claims. Upstream Zed compliance
statements do not transfer to Orion Studio.
