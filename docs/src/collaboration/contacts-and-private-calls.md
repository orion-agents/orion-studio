# Contacts and Private Calls {#contacts}

Contacts and private calls require an operator-deployed account and
collaboration service. The operator defines how users are discovered,
authenticated, blocked, and removed.

After the service is configured, use the `+` control beside **Contacts** to add
a person, then use that contact's menu to start a call. A private call behaves
like a temporary [channel](./channels.md) without persistent channel notes.

Only connect with people you trust. Voice, screen, and project-sharing data are
subject to the configured operator's privacy and retention policy.
