## 4. 已知约束与诚实边界

- **网络不可达**：若首次构建需要拉取依赖，H0 会失败。届时必须先解决网络或改走已有产物路径，不能假装可行。
- **构建耗时**：`target` 已迁至 USB 外置卷，全量/增量构建均比内盘慢；一次完整构建预计 20–60 分钟量级。每个实现轮次都需重建与验证，因此本目标是**多轮长任务**，不是单次响应可完成。
- **`thread_view.rs` 体量**：533 KB / 12,128+ 行，Center 模式改动集中在 `render` 组装段（12454–12484）与新增的阅读列辅助函数，不改其内部逻辑（符合 §4.7.5）。
- **不越界**：不改 ACP 协议、不改 sidecar、不重写数据/状态模型（§3.2）。
- **验收纪律**：F 组每条必须附真实窗口截图；仅凭代码或单测不得关闭。
