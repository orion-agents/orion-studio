# Security Policy

## Supported Release

Security review and fixes are scoped to the latest Orion Studio **macOS Apple
Silicon Preview** published as a GitHub Pre-release. Older Preview builds,
source builds, development builds, unsigned artifacts, and unsupported
platforms are outside the supported release scope.

This policy does not promise a response time, remediation time, bounty, or
continued support period.

## Report a Vulnerability Privately

Submit a private
[GitHub Security Advisory](https://github.com/orion-agents/orion-studio/security/advisories/new).
Do not disclose exploit details, credentials, private source code, tokens, or
personal data in a public issue.

Include, when available:

- affected GitHub release tag and DMG SHA-256;
- macOS version and Apple chip model;
- impact and affected component;
- minimal reproduction steps or a proof of concept;
- whether the behavior also appears in upstream Zed; and
- redacted logs, crash reports, or screenshots needed to reproduce the issue.

If the private advisory form is unavailable, open a
[minimal public issue](https://github.com/orion-agents/orion-studio/issues/new/choose)
requesting a private reporting path without including sensitive details.

## Public Security Issues

Use GitHub Issues only for non-sensitive hardening work or for vulnerabilities
that have already been coordinated and publicly disclosed. Reports affecting a
third-party service or upstream project may also require reporting through that
provider's own security process; an Orion Studio advisory does not replace it.
